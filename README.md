# Anime Portfolio

An anime-themed, single-page portfolio website. Dark neon aesthetic with Japanese typography accents.

## Features

- Glitch hero - RGB-split animated KINX title with speed lines
- Sakura petals - canvas-based drifting petal animation
- Terminal bio - animated typing effect
- RPG skill stats - scroll-triggered neon progress bars
- Episode cards - projects labeled EP.01 / EP.02 / EP.03 with hover glow
- UI polish - custom cursor, scroll progress bar, scanline overlay, blur nav, responsive

## Run It

Open index.html in a browser. No build step, no dependencies. One file.

## Deploy (GitHub Pages)

1. Repo Settings -> Pages
2. Source: Deploy from a branch -> anime-portfolio -> / (root)
3. Live at: https://kinxkenjiemartinez62-cpu.github.io/Portfolio/

## Tech

Pure HTML + CSS + vanilla JS. Zero libraries.
